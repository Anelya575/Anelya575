## Featured Projects

### 📊 Reddit vs Data Job Market

**Comparing online career discussions with employer demand for data skills**

Analyzed 120,000+ LinkedIn job postings alongside Reddit career discussions to investigate which technical skills employers request, how requirements vary across roles and experience levels, and whether online career discussions reflect actual employer demand. Built an end-to-end analysis pipeline including skill extraction from unstructured text, statistical testing, salary analysis, and machine learning.

**Key finding:** Reddit discussions showed a very strong correlation with employer skill demand (Spearman ρ = 0.919).

**Methods:** Chi-square testing · Bonferroni correction · Spearman correlation · Linear regression · Classification  
**Stack:** Python · pandas · PySpark · SciPy · scikit-learn

🔗 **[GitHub Repository](https://github.com/Anelya575/job-postings-reddit)**

### 💬 Dating App Survey Analysis

**Exploring dating app use, sexual self-consciousness, and sexual satisfaction through statistical analysis**

Cleaned and recoded real-world survey data, assessed scale reliability, and applied correlation, t-tests, and mediation analysis to test research hypotheses. Translated statistical results into clear conclusions about which hypotheses were supported, using visualizations and interpretation to communicate the findings beyond p-values and test statistics.

**Key finding:** Sexual self-consciousness was significantly associated with lower sexual satisfaction, while the remaining primary hypotheses were not supported.

**Methods:** Cronbach's Alpha · Correlation · t-tests · Mediation Analysis  
**Stack:** Python · pandas · SciPy · Pingouin · Matplotlib · Jupyter

🔗 **[GitHub Repository](https://github.com/Anelya575/dating-app-survey-analysis)**

### 🧩 Neura-Linker

**Student-matching system combining similarity-based recommendations with clustering**

Collaborated in a team of 4 to build a Python-based matching system that recommends each user's top 3 matches based on academic, social, and personal compatibility. Developed the weighted similarity algorithm behind the 0–100 compatibility score, combining feature comparisons with Jaccard similarity for multi-select preferences. Contributed to the K-Means clustering workflow using feature encoding and scaling, with the number of clusters evaluated through Elbow and Silhouette methods.

**Methods:** Weighted Similarity · Jaccard Similarity · K-Means Clustering · Feature Encoding · Feature Scaling  
**Stack:** Python · pandas · NumPy · scikit-learn · Matplotlib
